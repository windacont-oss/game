# GDD (Unity): Neo-City17

## Цель
Сделать FPS с атмосферой, ритмом и игровыми принципами, вдохновлёнными HL2, но на Unity и с оригинальными ассетами.

## Core loop
Исследование -> бой -> физ./пространственная задача -> сюжетный бит.

## Механики v1
- FPS movement
- Hitscan оружие
- Враги ближние/дальние
- Интерактивные объекты (кнопки/двери/подбор)
- Чекпоинты

## Vertical Slice
- 20 минут играбельного контента
- 1 полноценная глава
- 3 типа арен
- 2 типа врагов
- 3 оружия
