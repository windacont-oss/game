# Source SDK 2013 — setup для одиночной кампании

## 1. Подготовка
1. Установить Steam + Source SDK Base 2013 Singleplayer.
2. Клонировать `source-sdk-2013` и собрать `sp` solution.
3. Создать отдельную папку мода (`sourcemods/<modname>`).

## 2. Минимальная структура мода
- `gameinfo.txt`
- `maps/`
- `materials/`
- `models/`
- `scripts/`
- `sound/`
- `resource/`

## 3. Критичные настройки
- `sv_cheats 0` в боевом профиле.
- Явные skill-таблицы урона (`skill.cfg`).
- FOV и mouse input по современному стандарту (без «желе»).

## 4. Карты и пайплайн
- Blockout в Hammer.
- Быстрые компиляции на итерациях, финальный full compile на milestone.
- Скриптовые события только там, где это усиливает темп.

## 5. Профилирование
- Проверять FPS на репрезентативных сценах.
- Отдельно стресс-тестировать физику + дым + массовые NPC.
