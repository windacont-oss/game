# IMBA Bыт — Unity 3D прототип

Прототип "вайбовой" бытовой игры в духе старого тревожного симулятора: игрок живет в квартире и держит быт под контролем.

## Что уже реализовано
- Главное меню со стартом и выходом.
- Игровой цикл по дням: энергия, стресс, провал при перегрузе.
- Задачи на день: уборка, готовка, мусор, душ и т.д.
- Взаимодействие с объектами через `E` и raycast от камеры.
- Сон как переход на следующий день с штрафом за несделанные дела.
- HUD: день, фаза дня, энергия, стресс, деньги, чеклист задач.

## Базовая структура
- `Assets/Scripts/Core` — глобальное состояние игры.
- `Assets/Scripts/Gameplay` — задачи, интеракции, бытовые станции.
- `Assets/Scripts/UI` — меню и HUD.

## Как собрать сцену в Unity
1. Создай проект **Unity 2022.3 LTS (3D Core)**.
2. Скопируй папку `Assets` из этого репозитория.
3. Создай сцену `MainMenu`:
   - Canvas + две кнопки (`Start`, `Exit`).
   - Повесь `MainMenuController` и привяжи кнопки.
4. Создай сцену `HouseScene`:
   - Пустой объект `Bootstrap` с `GameState`.
   - Пустой объект `TaskBoard` с `TaskBoard`; добавь задания в инспекторе (ID: `clean_room`, `cook_food`, `take_out_trash`, `sleep`).
   - Player + Camera + `PlayerInteractor`.
   - На интерактивные объекты добавь коллайдеры и `InteractableTaskObject` (соответствующий `taskId`).
   - На кровать/холодильник/душ/мусорку добавь `UtilityStation`.
   - Canvas HUD + `HUDController` + TMP Text поля.
5. Добавь обе сцены в **Build Settings**.

## Вайб/арт-направление
- Цвета: приглушённые, тёпло-грязные (желтый свет лампы, выцветшие стены).
- Текстуры: потертости, пятна, неровные поверхности, легкий шум.
- Свет: низкая насыщенность, мягкие тени, легкий туман в комнате.
- Звук: гул холодильника, шаги по линолеуму, улица из окна, тихий ТВ-шум.

## Идеи для прокачки
- Система долгов/квартплаты (еженедельный дедлайн).
- Случайные события: протечка, сломанная плита, звонки от соседей.
- NPC-соседи и микродиалоги.
- Прогрессия квартиры (от хардкор-хаоса к уюту).
