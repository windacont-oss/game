# Neo-City 17 — концепт и стартовый каркас Source-мода

Это **практичный старт** для создания игры на движке Source, максимально близкой по ощущениям к Half-Life 2: структура глав, механики, темп, боевая песочница, музыка, арт-пайплайн и контроль качества.

> Полностью сделать игру уровня HL2 «под ключ» в одном коммите невозможно (это годы работы команды), но здесь заложен **играбельный фундамент** и подробный production-план, по которому можно реально двигаться.

## Быстрый старт

Подробная инструкция по запуску: `docs/RUN_GUIDE_RU.md`.

```bash
bash tools/bootstrap_source_mod.sh neo_city17
```

Или запуск через авто-лаунчер (создаст каркас/симлинк и откроет меню запуска):

```bash
bash tools/launch_mod.sh neo_city17
```

Скрипт создаст каркас `mod/` с каталогами для карт, скриптов, материалов, звука и NPC-конфигов.

## Как сделать «очень похоже на HL2», но безопасно

1. Повторять **принципы дизайна** (ритм, контраст, environmental storytelling), а не копировать контент.
2. Делать собственные модели, текстуры, музыку и реплики.
3. На каждом уровне держать цикл: исследование → бой → физическая головоломка → кат-сцена/эмоция.
4. Рано довести до играбельности 20–30 минут и только потом расширять.
