# Super3DRunner (Godot 4)

Небольшая 3D-игра на Godot: собери все кристаллы, избегай ловушек и дойди до портала.

## Управление

- `W/A/S/D` — движение
- `Space` — прыжок
- `R` — перезапуск
- `Esc` — освободить курсор

## Запуск

1. Откройте проект в Godot 4.2+
2. Запустите сцену `scenes/world.tscn` или весь проект.
